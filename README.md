# Stargem
Мультиагентная система для разработки
## Фронтенд
Работает на React + TS + NextJS

Запуск фронтенда:
```cmd
pnpm install

cd frontend

npm run dev
```
## База данных
PostgreSQL + pgadmin

*Перед развертыванием необходимо проверить, чтобы порт `5432` был свободен*

Развертывание:
```cmd
docker-compose up -d --build
```

Запуск:
```cmd
docker-compose up -d
```
Админ панель будет доступна на локальной машине по адресу: `http://localhost:5050/`
### Подключение БД к pgadmin
Servers > Регистрация > Сервер...

Общие:
- Имя: `Stargem DB`

Соединение:
- Имя/адрес сервера: `db`
- Порт: `5432`
- База данных обслуживания: `stargem`
- Имя пользователя: `postgres`
- Пароль: `0xStargem`
- Сохранить пароль? `ВКЛ`
*т. к. указано в docker-compose.yml*
## Бэкенд
Используется пакетный менеджер UV и FastAPI

*Перед началом настройки виртуального окружения необходимо создать файл `.env` и вставить в него содержиое файла `.env.example`*

```cmd
uv sync

uv run main.py
```
## Миграции
За миграции в проекте отвечает Alembic, *применять миграции можно только после развертывания БД и настройки виртуального окружения*

Применить миграции:
```cmd
uv run alembic upgrade head
```
